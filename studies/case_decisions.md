# Case decisions — PillarMind × Kimi

The record of the operator's case-by-case decisions: parent-and-child readings under DECISIONS
N49, and any similar case a standing rule routes here instead of deciding in advance.

**Append-only.** One dated entry per decision. An entry is never edited or deleted; a later
decision that changes it is a new entry that names the one it supersedes.

**Format per entry:**

```
## YYYY-MM-DD — <short title>
- Rule: <the DECISIONS entry that routes this case here, e.g. N49>
- Subjects: <who, as the rule allows them to be named>
- Decision: <what the operator decided>
- Scope: <what the decision allows, and what it does not>
- Supersedes: <earlier entry, or "none">
```

Nothing recorded here goes into civic output (N49).
